# Путь к 150 кг

## Персональный генератор

### Исправление v2 (12 октября 2026)

Актуальный алгоритм находится в `engine-v2.js`, подключается после `generator.js`. Последний сохраняет проверку формата и реализацию v1 для совместимости/регрессионных тестов; интерфейс использует только v2.

Убраны последовательные понижения расчётного максимума. Формула по подходу используется как приблизительная оценка; разница между жимом с паузой и без неё уточняется фактической тренировкой, без фиксированного штрафа. Для 132,5 × 3 первый день: 115 × 1, условный 120 × 1 только при RPE первого ≤6, затем 105 × 4 × 3. Силовые недели доходят до более высокой интенсивности; подводка привязана к оставшимся дням и снижает объём, сохраняя контрольные одиночные.

После записи результата доступна ограниченная поправка будущих весов с отдельным применением. RPE ≤5, боль, неподтверждённая пауза и устаревшие записи не повышают базу. Повышение ограничено шагом/2,5% и частотой раз в 7 дней, в подводке отключено. Перегрузка даёт предложение снижения. Цель не задаёт нагрузку; таблица RPE и проценты — правила алгоритма, не доказанный прогноз результата.

При загрузке автоматически мигрируют планы `bench-natural-1`: сохраняются ID, все даты, журналы и целиком любые дни с фактическими записями. Первоначальная библиотека сохраняется в `mg150-planner-v1-before-v2`; её можно скачать через «Мои данные». Обновление повторно не применяется. Импорт v1 тоже обновляет только незаписанные дни. Поправки по журналу сохраняют также все прошедшие дни.

Проверки v2: `node --test generator.test.cjs engine-v2.test.cjs` — совместимость v1, 432 комбинации профилей v2, содержательные регрессии нагрузки, подводка, миграция, ограничения пересмотра и сохранность факта. Технические проверки не доказывают физиологическую эффективность; она оценивается по реальным тренировкам. Полная актуальная методика — `method.html`.

Кнопка «Создать план»: жим лёжа для взрослых 18–85 лет на 4–24 недели. Учитываются возрастная группа, стаж, восстановление, текущий максимум или рабочий подход, пауза, давность результата, дни недели и оборудование. Цель не используется как текущая сила. При неизвестном результате создаётся предварительный календарь подбора нагрузки без выдуманных килограммов. Полная методика и ссылки на исследования — `method.html`. Коэффициенты являются правилами продукта, а не валидированным прогнозом результата.

`engine-v2.js` — актуальный независимый расчёт; `generator.js` — проверка резервных копий и совместимость v1. `planner.js` — анкета, журнал и локальное сохранение. Поддерживаются исходный план и до 20 пользовательских программ. `plan.json` остаётся исходным планом, совместимым с MGym; генератор пока не синхронизируется с Android-приложением.

### Хранение и перенос

Ключ localStorage: `mg150-planner-v1`, схема версии 1: `active`, массив `plans` (полные неизменные календарные снимки), `logs` по ключу `идентификатор|YYYY-MM-DD`. Повторный вход загружает снимок, а не пересчитывает даты. Новые программы не заменяют старые. Журнал хранит фактические вес/повторы каждого подхода, RPE для контрольных одиночных и отмеченных последних рабочих подходов жима, статус и самочувствие. Пропуски не сдвигают план. Повторный вход не пересчитывает программу. Исключение — однократное исправление v1 → v2 с резервной копией; дальнейшие поправки применяются отдельной кнопкой.

«Мои данные» позволяет экспортировать JSON и импортировать после проверки структуры/размера. Импорт добавляет программы; совпадающие идентификаторы получают новые. Существующие результаты исходного плана имеют приоритет при конфликте. Повреждённое хранилище не перезаписывается автоматически; доступна выгрузка исходного содержимого. Изменения из другой вкладки блокируют устаревшую запись до перезагрузки. Ошибки квоты/доступа видны пользователю; последнюю неудачную запись можно выгрузить в файл.

БД не требуется. Для автоматической синхронизации между устройствами понадобятся отдельные авторизация и серверное хранилище. Сейчас нет сервера, аналитики или передачи анкеты третьим лицам. Очистка браузера удаляет локальные данные; резервная копия нужна для переноса и восстановления.

### Проверка

`node --test generator.test.cjs engine-v2.test.cjs` — 20 тестов: 144 сочетания профилей v1 и 432 сочетания v2, даты, округление, этапы нагрузки, миграция, RPE, пересмотр и импорт/экспорт. `node --check app.js`, `node --check planner.js`, `node --check generator.js`, `node --check engine-v2.js` — синтаксис. Вручную: создать программу, записать фактический подход, перезагрузить, экспортировать/импортировать копию, проверить мобильный экран 360×640.

Адаптивный статический сайт с планом жима лёжа на 12 октября — 5 декабря 2026 года. Содержит 23 занятия, таблицы каждого подхода, время отдыха, вспомогательные упражнения и правила коррекции нагрузки. Один источник данных `plan.json` копируется в MGym как `app/src/main/assets/bench150-plan.json`.

## Просмотр

Основные файлы: `index.html`, `style.css`, `app.js`, `generator.js`, `engine-v2.js`, `planner.js`, `method.html` и исходный `plan.json`. Для локального просмотра запустите любой статический сервер в каталоге проекта, например `npx serve .`, и откройте указанный адрес. GitHub Pages можно настроить на корень ветки `main` после проверки PR.

Вес вспомогательных упражнений выбирается по указанному критерию запаса повторов: исходных результатов по ним нет. 150 кг в день проверки — условная попытка после уверенного чистого подъёма 142,5 кг. Исходные 132,5 × 3 были выполнены почти без паузы, поэтому план не приравнивает их к результату с паузой.
