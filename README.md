# MGym · планы жима, приседа и становой тяги

Календарь подготовки к выбранной дате с разминкой, рабочими подходами, отдыхом и подсобными упражнениями. Генератор рассчитан на подготовку без фармакологии. Название «Путь к 150 кг» — название проекта: личную цель можно задать другую.

## Три дисциплины

Выберите жим, присед или становую тягу. Сила и факты каждого движения независимы. Присед использует подтверждение глубины и фиксации, тяга — старта с пола без отбива и фиксации. В тяге исходно один основной день в неделю и до двух рабочих подходов; остальные занятия лёгкие. Подсобная работа включает иллюстрированные сплит-приседы, сгибание ног и ягодичный мост.

Текущие планы согласуются: если присед и тяга стоят ближе двух суток, второе занятие становится лёгкой техникой. Участвует выбранный текущий план каждой дисциплины, остальные остаются в библиотеке. Факты сохраняются. Нагрузка самостоятельных тренировок вне генератора пока не учитывается автоматически; совмещённый соревновательный старт требует индивидуального разбора.

Алгоритм жима сохраняет имя `bench-natural-3`, новые движения — `strength-natural-4`. Копии с ними требуют MGym 0.4.0 или обновлённого сайта. [Конфиденциальность](https://mgym.mg-trener.com/privacy.html) · [Поддержка](https://mgym.mg-trener.com/support.html).

Исправление прогрессии из MGym 0.5.1 действует и на сайте: у новичков плановые веса меняются по неделям с разгрузкой, а запросы вроде 70 → 200 кг явно отмечаются как неподтверждённые. Цель не подставляется вместо текущей силы. Старые программы пересчитывают только будущие дни; исходную копию можно скачать через «Мои данные».

Доработка октября 2026: старый результат теперь задаёт короткий возврат, а не ограничивает все 18–20 недель одним диапазоном. В примере 75 кг с целью 100 кг за 19 недель рабочий вес меняется с 45 кг до 62,5 × 3 на 18-й неделе; каждая четвёртая неделя разгрузочная. Вес не повышается до заявленной цели без фактов. Пояснение расчёта в календаре сокращено, полная методика вынесена на отдельную страницу.

## Быстрый старт

1. Нажмите **«Создать план»**. Укажите возраст, массу тела, стаж, восстановление, доступные дни, цель и даты подготовки.
2. Укажите известный результат: вес, повторения, условия выполнения и RPE, если он известен. Жим без паузы не приравнивается к подтверждённому максимуму с паузой. Если результата нет, используйте режим без известного максимума.
3. Проверьте предварительный расчёт и сохраните программу. Выберите неделю и день: таблица показывает разминку, рабочие подходы, отдых и целевой RPE там, где он нужен.
4. После занятия нажмите **«Записать факт»**: внесите реальные килограммы и повторения, RPE у отмеченных жимов, статус и самочувствие. Подтверждайте паузу и отсутствие боли только при их соблюдении.
5. Прочитайте **«Проверку нагрузки»**. Если предложена поправка, сначала посмотрите изменения, затем подтвердите применение. Само сохранение факта не означает обязательного повышения веса.

## Возможности и границы

| Параметр | Текущая реализация `bench-natural-3` |
| --- | --- |
| Частота | 1–4 выбранных дня в неделю |
| Длительность | 14–730 дней; длинная подготовка разбита на повторяющиеся блоки |
| Возраст | 14–100 лет; до 18 и после 85 — только с индивидуальным сопровождением, без автоматических максимальных попыток |
| Масса тела | 20–400 кг; масса не превращается в искусственный множитель силы |
| Нагрузка | Вес, подходы, повторения, отдых, целевой RPE; округление к доступному шагу веса |
| Восстановление | Разгрузки, лёгкие занятия, снижение объёма перед целью и облегчение после недовосстановления |
| Подсобная работа | Тяги, трицепс и задняя дельта с иллюстрациями; дозировка зависит от частоты и восстановления |
| Программы | Несколько сохранённых планов и исходный фиксированный план 2026 года |

Программа рассчитана на три силовых движения. Она не заменяет индивидуальную подготовку при медицинских ограничениях и не гарантирует заданный рекорд. Возрастные поправки условны: фактическая переносимость нагрузки важнее одной цифры возраста. Правила и источники изложены в [методике](https://mgym.mg-trener.com/method.html).

## Как работает пересчёт

- Оценка силы использует фактические **1–10 повторов с RPE 6–9**, подтверждённой паузой и выполнением условий тренировки. Дополнительные повторения учитываются вместе с RPE; записывать нужно выполненное, а не предполагаемое.
- Несколько подходов и последних занятий сглаживаются медианой. Для повышения нужны два согласованных занятия; прибавка базы ограничена 2,5%, между повышениями — минимум неделя. Округление может оставить видимый рабочий вес прежним.
- Для двух полностью выполненных рабочих частей с большим запасом предусмотрена небольшая пробная прибавка. Максимум по очень лёгкому RPE не вычисляется.
- Высокое усилие, недобор повторений, тяжёлое самочувствие или пропуск могут привести к облегчению ближайшей тренировки: меньше веса, подходов и повторений, больше отдыха, ниже целевой RPE.
- Боль блокирует автоматический пересмотр нагрузки. Последние семь дней перед целью база не повышается.
- Меняются только будущие дни без записанного факта. Прошлое, текущий день и записанные подходы сохраняются. Повторное применение той же записи не даёт повторной прибавки.

Первая соревновательная попытка — предварительный ориентир по текущей базе, а не прогноз силы к выбранной дате. Следующие попытки выбираются по фактической готовности.

## Перенос даты и изменение расписания

Откройте **«О плане и расчёте → Изменить цель и расписание»**. Например, можно перенести выступление с декабря на февраль, изменить целевой вес, доступные дни и восстановление.

Перед применением показывается предварительный результат. Сохраняются идентификатор программы, прошлые дни, сегодняшний день и любые частично записанные будущие занятия. Новая дата должна быть минимум через 14 дней от дня изменения; общая длина плана ограничена двумя годами от исходного старта. После длительного перерыва назначается облегчённый возврат.

## Сохранение и перенос данных

Сайт хранит программы и факты **в браузере на этом устройстве**. Повторный вход не сдвигает календарь. Серверная БД, регистрация и автоматическая синхронизация не используются. Для открытия сайта нужна загрузка его файлов; автономное использование доступно во встроенном планировщике MGym.

- **«Мои данные»** позволяет скачать JSON-копию программ и загрузить её на сайте или в MGym.
- Другой браузер, другой адрес сайта и другое устройство имеют отдельное хранилище. Очистка данных браузера или завершение приватного сеанса могут удалить записи.
- Импорт проверяется и требует подтверждения. Существующие программы сохраняются; совпавшие программы могут добавляться отдельной копией.
- При переходе с генераторов v1/v2 создаётся локальная резервная копия до миграции. Прошлые и записанные дни сохраняются.

В MGym сохранённый факт также попадает в обычную историю приложения, включая подсобные упражнения. Между сайтом и телефоном перенос выполняется вручную через JSON. Полный календарь генератора и копия дневника Android — разные резервные копии.

## Для разработчика

Статический сайт на HTML, CSS и JavaScript без сборщика и серверной части. GitHub Pages публикует корень ветки `main`.

| Файл | Назначение |
| --- | --- |
| `index.html`, `style.css`, `app.js` | Интерфейс, календарь и таблицы занятий |
| `planner.js` | Формы, журнал факта, хранение, импорт и применение пересчёта |
| `engine-v3.js` | Актуальная генерация, адаптация и перенос цели |
| `generator.js`, `engine-v2.js` | Общая валидация, совместимость и прежние алгоритмы |
| `plan.json` | Исходный фиксированный план 2026 года |
| `method.html`, `AUDIT-V3.md` | Методика, ограничения и результаты аудита |
| `assets/` | Иллюстрации упражнений |

Локальный запуск из корня репозитория при установленном Python:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8765/`. Используйте HTTP-сервер: прямое открытие `index.html` не обеспечивает загрузку JSON.

Проверка расчётов при установленном Node.js:

```sh
node --test generator.test.cjs engine-v2.test.cjs engine-v3.test.cjs disciplines.test.cjs
```

Набор содержит 40 тестов, включая 120 сочетаний профилей v3 и 432 сочетания v2. Проверяются перенос даты, многоповторная адаптация, повторное сохранение, боль, восстановление и совместимость. Для v3 также проверен браузерный сценарий создания, записи факта и переноса цели на ширинах 390 и 1280 пикселей.

Ключ браузерного хранилища — `mg150-planner-v1`; резервная копия перед миграцией — `mg150-planner-v1-before-v3`. Номер формата хранения не равен версии алгоритма. В [MGym](https://github.com/MG-Trener/MGym) сайт переносится скриптом `tools/sync-bench-planner.cjs`; вычислительные файлы сохраняются побайтно, версия источника и контрольные суммы записываются в `source.json`.
