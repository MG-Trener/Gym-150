# Путь к 150 кг

## Персональный генератор

Кнопка «Создать план»: жим лёжа для взрослых 18–85 лет на 4–24 недели. Учитываются возрастная группа, стаж, восстановление, текущий максимум или рабочий подход, пауза, давность результата, дни недели и оборудование. Цель не используется как текущая сила. При неизвестном результате создаётся предварительный календарь подбора нагрузки без выдуманных килограммов. Полная методика и ссылки на исследования — `method.html`. Коэффициенты являются правилами продукта, а не валидированным прогнозом результата.

`generator.js` — независимый расчёт и проверка резервных копий. `planner.js` — анкета, журнал и локальное сохранение. Поддерживаются исходный план и до 20 пользовательских программ. `plan.json` остаётся исходным планом, совместимым с MGym; генератор пока не синхронизируется с Android-приложением.

### Хранение и перенос

Ключ localStorage: `mg150-planner-v1`, схема версии 1: `active`, массив `plans` (полные неизменные календарные снимки), `logs` по ключу `идентификатор|YYYY-MM-DD`. Повторный вход загружает снимок, а не пересчитывает даты. Новые программы не заменяют старые. Журнал хранит фактические вес/повторы каждого подхода, RPE только для отмеченных одиночных жимов, статус и самочувствие. Пропуски не сдвигают план. Обновление сайта не пересчитывает сохранённые программы.

«Мои данные» позволяет экспортировать JSON и импортировать после проверки структуры/размера. Импорт добавляет программы; совпадающие идентификаторы получают новые. Существующие результаты исходного плана имеют приоритет при конфликте. Повреждённое хранилище не перезаписывается автоматически; доступна выгрузка исходного содержимого. Изменения из другой вкладки блокируют устаревшую запись до перезагрузки. Ошибки квоты/доступа видны пользователю; последнюю неудачную запись можно выгрузить в файл.

БД не требуется. Для автоматической синхронизации между устройствами понадобятся отдельные авторизация и серверное хранилище. Сейчас нет сервера, аналитики или передачи анкеты третьим лицам. Очистка браузера удаляет локальные данные; резервная копия нужна для переноса и восстановления.

### Проверка

`node --test generator.test.cjs` — даты и неизменность календаря, границы входных данных, 144 сочетания профилей, безопасные веса, RPE, подводка, импорт/экспорт. `node --check app.js`, `node --check planner.js`, `node --check generator.js` — синтаксис. Вручную: создать программу, записать фактический подход, перезагрузить, экспортировать/импортировать копию, проверить мобильный экран 360×640.

Адаптивный статический сайт с планом жима лёжа на 12 октября — 5 декабря 2026 года. Содержит 23 занятия, таблицы каждого подхода, время отдыха, вспомогательные упражнения и правила коррекции нагрузки. Один источник данных `plan.json` копируется в MGym как `app/src/main/assets/bench150-plan.json`.

## Просмотр

Сайт состоит из `index.html`, `style.css`, `app.js` и `plan.json`. Для локального просмотра запустите любой статический сервер в каталоге проекта, например `npx serve .`, и откройте указанный адрес. GitHub Pages можно настроить на корень ветки `main` после проверки PR.

Вес вспомогательных упражнений выбирается по указанному критерию запаса повторов: исходных результатов по ним нет. 150 кг в день проверки — условная попытка после уверенного чистого подъёма 142,5 кг. Исходные 132,5 × 3 были выполнены почти без паузы, поэтому план не приравнивает их к результату с паузой.
