Конфиденциальность MGym и MG150

Редакция от 12 октября 2026 года. Разработчик: Михаил Гаврилычев. Контакт: WhatsApp +7 701 870 93 84.

Что хранится

Возраст, масса тела, результаты упражнений, RPE, самочувствие, даты, планы и настройки хранятся локально: в базе MGym на телефоне или в хранилище браузера сайта. Эти данные используются для дневника, расчёта нагрузки и статистики. Разработчик не получает их автоматически. Регистрации, рекламы, аналитических и рекламных SDK нет. Доступ к Health Connect, HealthKit, контактам и геолокации не используется.

Сеть и внешние сервисы

Версия Android из GitHub обращается к GitHub для проверки обновлений. Магазинная сборка использует обновления Google Play и не запрашивает GitHub в фоне. При открытии сайта, ссылок, скачивании APK и файлов внешний сервис получает обычные сетевые сведения, в том числе IP-адрес; действуют его правила. Хостинг сайта — GitHub Pages. Приложение не добавляет к этим запросам тренировочный журнал.

По кнопке WhatsApp открывается внешний чат: отправляется только то, что вы самостоятельно решите отправить. Разработчик использует полученные обращения для ответа и улучшения программы. Если хотите удалить отправленные разработчику сведения, обратитесь в этот же чат; удаление копий у WhatsApp регулируется сервисом.

Экспорт, срок хранения и удаление

JSON и CSV сохраняются только в выбранное вами место. При выборе облачного диска файл передаётся выбранному провайдеру по вашему действию. Автоматической синхронизации сайта и приложения нет. Записи остаются на устройстве до очистки данных или удаления. В MGym есть «Настройки → Удалить все данные»; на сайте данные удаляются через настройки браузера. Резервные файлы нужно удалять отдельно. Перед очисткой сохраните копии дневника и программ, если они нужны. Облачное резервирование Android отключено.

Разрешения и возраст

Файлы выбираются системным диалогом без общего доступа к накопителю. Вибрация служит обратной связью. Уведомления запрашиваются только в версии GitHub для обновлений. Генератор не предназначен для детей младше 14 лет; в 14–17 лет требуется индивидуальное сопровождение. Приложение не является медицинским изделием и не диагностирует, не лечит и не предотвращает заболевания.
