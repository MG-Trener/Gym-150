MGym privacy policy

Updated 13 October 2026. Developer: Mikhail Gavrilychev. WhatsApp +7 701 870 93 84.

Data on your device

Age, body weight, exercise results, RPE, wellbeing, dates, plans and preferences, including your selected language, are stored locally in MGym or the website browser. They support the diary, training estimates and statistics. The developer does not automatically receive these records. There are no accounts, advertising or analytics SDKs. The app does not access Health Connect, contacts or location.

Network and external services

The GitHub Android version contacts GitHub to check for updates. The store build uses Google Play updates and does not check GitHub in the background. Opening a website, link or download lets the external service receive normal network information, including your IP address, under its own policies. This website is hosted on GitHub Pages. Training records are not attached to those requests.

WhatsApp opens an external chat. Only information you choose to send is shared. The developer uses your messages to reply and improve MGym. To request deletion of information sent to the developer, contact the same chat. Copies held by WhatsApp are governed by that service.

On eligible Google Play installations, Android may provide app quality reports through Android vitals if the user allows system diagnostics. This is a Google platform service, not an analytics SDK embedded in MGym.

Export, retention and deletion

JSON and CSV are saved only to the destination you select. Choosing cloud storage transfers the file to that provider on your instruction. There is no automatic website/app synchronization. Local records remain until you clear data or remove the app. Use Settings → Delete all data in MGym, or clear site storage in your browser. Delete exported backups separately. Back up both the diary and training plans first if needed. Android cloud backup is disabled. There is no user account to delete.

Permissions and age

Files use the system picker, without broad storage access. Vibration provides feedback. Update notifications are requested only by the GitHub version. The generator is not intended for children under 14; ages 14–17 require individual supervision. MGym is not a medical device and does not diagnose, treat, cure or prevent diseases.
